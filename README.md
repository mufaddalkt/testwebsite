# Attendly — School Attendance Demo

A minimal, responsive school attendance test website built with HTML5, CSS and JavaScript.

## Features
- Three fictional classes (8-A, 9-A, 10-A)
- Mark individual students present or absent
- Search students, select a date and class
- Daily statistics and bulk mark present
- Reset day with confirmation and download CSV reports
- Browser localStorage persistence for each class and date

## Running
Open `index.html` locally or deploy the repository as a static website on Vercel. No build command is required.

**Demo only:** This is not a production attendance system. There is no login, shared database, access control or audit trail. All attendance is stored only in your browser and can be cleared. Use fictional student information only.
